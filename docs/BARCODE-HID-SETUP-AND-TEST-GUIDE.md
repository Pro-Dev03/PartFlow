# دليل إعداد واختبار ماسح الباركود

## النطاق

يدعم PartFlow ماسحات الباركود التي تعمل بوضع **USB HID Keyboard** أو **Bluetooth HID Keyboard**. في هذا الوضع يتعامل النظام مع الماسح كأنه لوحة مفاتيح، لذلك لا يحتاج إلى تعريف خاص داخل التطبيق.

لا يشمل هذا الدليل أجهزة RS232 أو الأجهزة التي تحتاج SDK خاصًا؛ هذه تحتاج تكاملًا منفصلًا أو برنامجًا وسيطًا.

## إعداد الجهاز

1. وصل الماسح بمنفذ USB، أو اربطه عبر Bluetooth.
2. اجعل وضع الاتصال `HID Keyboard` إذا كان الجهاز يدعم أكثر من وضع.
3. اضبط الجهاز ليضيف مفتاح `Enter` بعد كل عملية مسح.
4. اختبره أولًا في Notepad. يجب أن تظهر قيمة الباركود ثم ينتقل المؤشر إلى سطر جديد.
5. لا تستخدم وضع RS232 أو Serial مع نسخة المتصفح أو Electron إلا بعد إضافة تكامل خاص.

## إضافة منتج جديد

المسار المعتمد حاليًا:

```text
التصنيفات -> إضافة منتج لهذا التصنيف -> حقل الباركود -> تفاصيل المنتج -> حفظ
```

عند فتح نموذج منتج جديد يكون حقل الباركود نشطًا تلقائيًا. يمكن للماسح إدخال القيمة ثم إرسال `Enter`. الباركود يُحفظ في المنتج، وليس في التصنيف.

## الاستخدام في نقطة البيع

حقل البحث والباركود في نقطة البيع موجود داخل نموذج. عند إرسال الماسح للباركود ثم `Enter` ينفذ النظام البحث ويضيف المنتج أو يعرض مسار الباركود غير المسجل.

## قواعد الباركود

- يقبل النظام باركودات رقمية أو حروفية.
- يمكن استخدام EAN وUPC وCode 128 وCode 39 طالما أن الجهاز يرسلها كنص.
- لا يُنشأ منتج جديد تلقائيًا لمجرد أن الباركود غير معروف؛ يجب تأكيد تفاصيل المنتج وحفظه.
- لا يسمح النظام بإنشاء منتج جديد بباركود موجود مسبقًا.
- المنتجات التي لا تملك باركودًا يمكن إدارتها باستخدام SKU أو المعرف الداخلي.

## اختبار قبول يدوي

### اختبار HID

1. افتح شاشة المخزون.
2. افتح إضافة منتج من التصنيف أو من زر إضافة المنتج.
3. اترك التركيز على حقل الباركود.
4. امسح باركودًا حقيقيًا.
5. تأكد من ظهور القيمة كاملة وعدم وجود مسافات أو أحرف ناقصة.
6. تأكد من انتقال النموذج أو تنفيذ `Enter` حسب المسار.

### اختبار باركود غير موجود

1. امسح باركودًا غير مسجل.
2. يجب أن يفتح نموذج منتج جديد أو مسار الإضافة.
3. يجب أن تبقى قيمة الباركود موجودة في النموذج.
4. أكمل الاسم والسعر والتصنيف واحفظ.
5. تحقق من ظهور المنتج في المخزون والمشتريات ونقطة البيع.

### اختبار التكرار

1. امسح باركود منتج موجود.
2. حاول حفظ منتج جديد بالقيمة نفسها.
3. يجب منع الحفظ وعرض رسالة تفيد بأن الباركود مستخدم.
4. يجب ألا يُنشأ سجل منتج إضافي.

### اختبار نقطة البيع

1. افتح نقطة البيع.
2. امسح باركود منتج موجود.
3. تحقق من العثور على المنتج وإضافته إلى السلة.
4. امسح المنتج نفسه مرة أخرى وتحقق من تطبيق قاعدة الكمية الحالية.
5. امسح باركودًا غير موجود وتحقق من ظهور رسالة واضحة.

## مصفوفة التوافق

| نوع الجهاز | التوافق |
|---|---|
| USB HID Keyboard | مدعوم مباشرة |
| Bluetooth HID Keyboard | مدعوم مباشرة |
| Wireless USB Receiver HID | مدعوم مباشرة |
| RS232 / Serial | يحتاج تكاملًا خاصًا |
| SDK خاص بالشركة | يحتاج تكاملًا خاصًا |
| كاميرا الهاتف أو المتصفح | غير مستخدمة في مسار المخزون الحالي |

## ملاحظات الإصدار

- يجب اختبار الماسح الفعلي قبل تسليم النظام للمتجر.
- يجب إبقاء الحقل المطلوب في حالة تركيز واضحة عند الاستخدام المتكرر.
- لا تعتمد الاختبارات على ماركة ماسح واحدة.
- يجب اختبار طول الباركود، الأحرف، ووجود `Enter` في إعدادات الجهاز.
- لا تُسجل كلمات مرور أو مفاتيح أو بيانات حساسة داخل تقارير الاختبار.
